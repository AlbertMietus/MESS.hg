glossary (MESAB)
================

.. glossary::

   MASAB

      I use the mnemonic :term:`MASAB` blog about system architecting; where I ‘invent’ the :term:`Natrix` framework. **MASAB** stands for *Modern, Agile
      System-Architecting Blog*.

   Natrix

      The control-loop framework that is being *‘system architected’* as studied in the :term:`MASAB`-blogs is called :term:`Natrix` A **Natrix-Natrix** is a
      kind of `ring-snake <https://en.wikipedia.org/wiki/Grass_snake>`_ and as the framework will be implemented in python (also a snake) and is about
      ‘loops’ (more or less a ring), this name is chosen — in my famous “5-minutes style”.
