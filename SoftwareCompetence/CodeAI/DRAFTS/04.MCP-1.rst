=======================
Agentic Coding with MCP
=======================

.. post:: 2026/10/05		
   :category: ScenerySketching
   :tags: CodeAI
   :location: Geldrop
   :language: en

   “Writing code” is more than just *writing text*. When human engineers work with code, they need a variety of tools to
   build (a **compiler**) and verify (several **test runners**) the software. We can enable LLMs to run these tools as
   well; this offers many benefits and can introduce huge risks.

   In this article, we introduce MCP, the protocol that enables *agentic AI*. But be warned! MCP is extremely powerful,
   and ---as an LLM has no conscience--- it will happily wipe all your work, or worse.  More on that in an upcoming
   article: :ref:`“MCP safety” <CodeAI-MCP2>`.
   |BR|
   Now we focus on how agentic coding fits into the scenery, and how we can speed up engineering by asking LLMs to run
   those tools for us.
